# 演示测试数据说明

## 目标

演示测试数据用于本地开发、页面走查和接口联调。应用启动后会自动插入一组固定的模拟家庭数据，覆盖备孕、孕期、生产、产后、宝宝、提醒、报表和 AI 审计等模块，方便直接查看现阶段功能。

## 启用方式

后端默认启用演示数据：

```yaml
babydust:
  demo-data:
    enabled: true
```

也可以通过环境变量控制：

```bash
BABYDUST_DEMO_DATA_ENABLED=true
```

如需关闭，设置：

```bash
BABYDUST_DEMO_DATA_ENABLED=false
```

单元测试默认关闭演示数据，避免污染普通测试用例；专门的 `DemoDataInitializerTest` 会单独启用并验证数据插入。

## 固定账号与空间

演示数据使用固定 ID，便于前后端联调和重复启动：

| 项目 | 值 |
| --- | --- |
| 演示 token | `bd_demo_seed_token` |
| 用户 ID | `11111111-1111-1111-1111-111111111111` |
| 家庭 ID | `22222222-2222-2222-2222-222222222222` |
| 孕期档案 ID | `33333333-3333-3333-3333-333333333333` |
| 妈妈档案 ID | `44444444-4444-4444-4444-444444444444` |
| 宝宝档案 ID | `55555555-5555-5555-5555-555555555555` |

小程序 H5 预览可进入“我的”页面，点击“载入演示数据”，前端会把上述 token、家庭 ID 和孕期档案 ID 写入本地会话。随后返回首页、记录、报表、时间线、提醒、AI 整理等页面即可查看演示数据。

## 数据覆盖范围

演示数据按真实孕育场景构造，日期会随当前日期滚动：

- 孕期档案：当前约为孕 `17+3`，自动计算末次月经和预产期。
- 孕期记录：体重、血压、症状、补剂、用药、胎动、心情、备注。
- 备孕记录：周期、排卵试纸、基础体温、同房、补剂。
- 生产记录：见红、宫缩、入院待产记录。
- 产后记录：恶露、情绪、补铁等恢复记录。
- 宝宝记录：喂养、睡眠、尿布、身高体重、日常备注。
- 检查报告：孕 7 周血检、孕 12 周建档血常规、家庭血压阶段汇总。
- 待办与提醒：产检、补剂、产后复查、宝宝疫苗、自定义提醒。
- AI 配置：DeepSeek provider、prompt、schema、阿里云 OCR 预处理器、安全问答策略。
- AI 审计：草稿生成、高风险问答拦截、低风险问答、OCR/ASR 降级、草稿确认历史。

## 幂等策略

每次后端启动时，初始化器会先删除演示家庭和演示账号关联的数据，再重新插入最新一批演示数据。因此重复启动不会产生重复记录，也不会清理非演示家庭的数据。

当前清理范围只包含固定演示用户、固定演示家庭、`demo-` 前缀 AI 配置和 `oss://demo/` 预处理日志。

## 本地接口验证

后端启动后可用以下接口检查演示数据：

```bash
curl -H "Authorization: Bearer bd_demo_seed_token" \
  "http://127.0.0.1:8080/api/v1/home/summary?familyId=22222222-2222-2222-2222-222222222222"
```

期望返回：

- `stage` 为 `pregnancy`。
- `pregnancy.gestationalWeekDisplay` 为滚动计算出的孕周。
- `recentRecords`、`recentReports`、`upcomingTodos`、`keyMetrics` 均有数据。

## 注意事项

演示数据只用于开发和演示环境。公开发布或生产环境应关闭 `babydust.demo-data.enabled`，避免生成固定 token 和模拟家庭数据。
